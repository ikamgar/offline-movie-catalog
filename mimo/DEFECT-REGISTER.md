# DEFECT REGISTER — Offline Movie Catalog v5.4.0

Baseline audit of the uploaded source (60 files, ~400 KB). Every phase prompt refers to these IDs; the final audit (P9) must tick each one off with evidence.

**Status legend**
- `RUN` — reproduced by executing code (scripts in `mimo/repro/`).
- `CODE` — deterministic from reading the source; not executed in the audit sandbox (no network → Express/ws were not installed).
- `LIKELY` — high confidence from framework defaults, not executed.

**Severity:** `P0` fix first (data loss / takeover / unusable) · `P1` high · `P2` medium · `P3` low.

Re-run the reproductions at any time:
```
node mimo/repro/repro-backend.js     # no npm install needed
node mimo/repro/repro-ui.js          # needs: npm i -D playwright && npx playwright install chromium
```
Exit code is 1 while any defect is still `PRESENT`.

## Working notes for the agent
- A bug marked `RUN` has a script; make that script print `FIXED`, and add a permanent regression test (P0 creates them as `todo` tests named with the ID).
- Bugs marked `CODE`/`LIKELY` must be reproduced by a test **before** fixing whenever feasible; if not reproducible, say so in the phase report.
- Never close a defect by weakening its check.
